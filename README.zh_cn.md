# SortNStock

[English](README.md) | 简体中文

一个客户端 Fabric 模组，用来整理容器、把快捷栏补齐。装有
[Litematica](https://github.com/sakura-ryoko/litematica) 和
[QuickShulker](https://github.com/KyrptonaughtMC/QuickShulker) 时会自动联动。

所有物品移动都是普通的容器点击，服务端会当成您自己点的一样逐次校验。模组不会生成物品，也不会
放置方块。服务端不需要装任何东西。

## 环境要求

| | |
|---|---|
| Minecraft | 26.1.x |
| Fabric Loader | 0.19.3+ |
| Java | 25（26.1 要 25，不是 21） |
| [MaLiLib](https://github.com/sakura-ryoko/malilib) | 0.28.11 – 0.28.x，必需 |
| Litematica | 0.27.11 – 0.27.x，可选 |
| QuickShulker | 任意 26.1 版本，可选 |
| Mod Menu | 可选，在模组列表里加一个配置按钮 |

## 安装

把模组和 MaLiLib 一起放进 `.minecraft/mods`。Litematica、QuickShulker、Mod Menu 只在用到对应
功能时才需要。

自己构建的话，用 Java 25 跑 `./gradlew build`。如果 Java 25 不是默认的 `JAVA_HOME`，要么在
`gradle.properties` 里设 `org.gradle.java.home`，要么把 `JAVA_HOME` 指过去。

## 快捷键

| 功能 | 默认键 |
|---|---|
| 整理光标下的容器 | 鼠标中键 |
| 打开配置界面 | `T` 然后 `K` |

另有四个选项可以绑切换快捷键，默认留空：启用自动补货、启用投影联动、启用从潜影盒补货、调试日志。

鼠标中键同时是原版的选取方块，一次点击会同时触发两边。整理真的开始时，这次点击的原版行为会被
抑制；创造模式下、悬停格子有物品时中键让给原版，复制和选取照常可用。

## 整理

鼠标指在容器里的某个格子上按快捷键，整理的是那一格所属的容器。指在自己背包上时整理的是 27 格
主背包，快捷栏、盔甲和副手都不动。

- 排序键可选：注册名、显示名、数量、耐久、组件或标签。固定顺向。
- 先合并零散堆叠，再把结果往前排紧。
- 潜影盒留在容器最后几格，前面空出一段。这一块内部先按填充状态（空盒、未满、满），再按颜色
  （创造物品栏顺序），再让杂盒排在纯净盒前，最后按内容物。
- 只移动您本来就有的物品。无法安全移动的组合会直接跳过，不去冒险弄乱整个容器。

## 自动补货

模组用您已有的物品把快捷栏和/或副手补满。

- 触发条件是手里那一叠变少了，包括使用、放置、进食、投掷和饮用。往容器里存东西不会触发：开着
  界面时用不了物品，所以那不算消耗。
- `restockMinCount` 是阈值，0 到 64。设成 0 就是彻底用完才补。
- 每次补满一整组：多数物品是 64，鸡蛋、雪球之类是 16。
- 先找背包，再找当前开着的容器。
- 装了 QuickShulker 时，只放在随身潜影盒里的物品也能取出来。模组会开盒、取出、关盒，期间界面
  隐藏、声音静音，不打断手上的操作。

## 潜影盒与选取方块

原版的选取方块只对背包里已有的方块生效。对着一个自己没有的方块按中键时，模组会打开一个装着
它的潜影盒，把那一叠取出来，再按一次中键就能选中。

用的是同一个「启用从潜影盒补货」开关。创造模式会跳过，那里中键是复制物品。背包里本来就有这个
方块时，行为完全不变。

## 投影联动

装了 Litematica 并开启联动后，模组挂在它的 `schematicWorldPickBlock` 上，也就是切换快捷栏之前
的那一下，所以同一次右键就能用上补好的物品。

- 只在这一个位置介入，不做定时轮询。
- 如果需要的方块已经在背包的任何位置，模组什么都不做。Litematica 的选取方块能选中对应的快捷栏
  格子，也能从主背包里拿出来，没有可补的。
- 能补到哪些快捷栏格子，取自 Litematica 自己的 `pickBlockableSlots` 设置。
- 当这些格子全都有东西时，改为交换：盒子里的物品取出来，数量最少那一格的东西放进去。
- 盒子还开着的时候，这一次点击的轻松放置会被挡下，不会在物品到手之前先放错方块。

从盒子里取东西要几 tick，所以触发的那一次点击可能在补货完成前就结束了。物品出现后再按一次即可。

## 配置

所有设置都在 MaLiLib 的配置界面里，用快捷键、Mod Menu 按钮或 MaLiLib 自己的模组列表打开。分成
整理、自动补货、潜影盒、投影联动、调试、快捷键几个标签页，外加一个列出全部选项的总览页。

每一项的说明见 [`docs/CONFIG-REFERENCE.md`](docs/CONFIG-REFERENCE.md)。模组不往动作栏打字，反馈
只有音效，诊断信息写进日志（需开调试日志）。

## 已知问题

- 整理和补货都是容器点击。服务端如果拒绝或限流，结果可能和客户端显示的不一致。
- 投影联动的 mixin 针对 Litematica 0.27.x 的方法签名，之后的版本可能会改。mixin 配置只在装了
  Litematica 时生效，没装不会崩。
- 开潜影盒需要服务端也装 QuickShulker，因为用的是自定义数据包。没有的话功能不生效，也不会乱发包。
- 26.3 的移植在 `mc26.3` 分支上进行中。
