# SortNStock

[English](README.md) | **简体中文**

一个**客户端** Minecraft Fabric 模组，提供**背包整理**与**自动补货**，并可选联动
[Litematica](https://github.com/sakura-ryoko/litematica) 与
[QuickShulker](https://github.com/KyrptonaughtMC/QuickShulker)。

SortNStock 在设计上刻意保守：

- **纯客户端。** 服务端不需要安装任何东西。
- **绝不创造物品。** 没有生成、复制或「凭空补充」。每一次移动都是一次普通的容器点击
  （`PICKUP` / `SWAP`），服务端会像您亲手点击那样逐次校验。
- **绝不放置方块、不修改投影。** 放置是 Litematica 的职责，SortNStock 只负责把所需物品放进快捷栏。

## 环境要求

| | |
|---|---|
| Minecraft | 26.1.x |
| Fabric Loader | 0.19.3+ |
| Java | **25**（26.1 要求，不是 21） |
| [MaLiLib](https://github.com/sakura-ryoko/malilib) | 0.28.11 – 0.28.x（必需：配置与快捷键系统） |
| Litematica | 0.27.11 – 0.27.x（可选：投影联动） |
| QuickShulker | 任意 26.1 版本（可选：从潜影盒补货） |
| Mod Menu | 可选：在模组列表里加一个配置按钮 |

## 构建

```bash
./gradlew build
```

Gradle 必须运行在 **Java 25** 上。如果您的 Java 25 不是默认的 `JAVA_HOME`，请设置
`gradle.properties` 里的 `org.gradle.java.home`（或设置 `JAVA_HOME` 环境变量）。

## 快捷键

| 功能 | 默认键 |
|---|---|
| 整理光标下的容器 | **鼠标中键** |
| 打开配置界面 | **`T` 然后 `K`** |

以下四个选项也可以绑定切换快捷键，默认留空：*启用自动补货*、*启用投影联动*、
*启用从潜影盒补货*、*调试日志*。

鼠标中键同时是原版的「选取方块」，两者会在同一次点击触发。整理真正开始时会抑制该次的原版行为；
但在**创造模式**下、且悬停的格子有物品时，中键会让位给原版的复制/选取。

## 整理

把鼠标指在容器的槽位上按快捷键即可。模组整理该槽位所属的容器；指在自己的背包上时，整理的是
**27 格主背包** —— 不包含快捷栏、盔甲与副手。

- **排序键**：注册名、显示名、数量、耐久、NBT/组件、标签。固定为顺向。
- **始终合并**同一物品的零散堆叠，然后**向前紧凑排列**。
- **潜影盒被保留到容器的最后几格**，其前方留有间隙。末尾块内部依次按：填充状态
  （空盒 → 未满 → 满）→ 颜色（创造栏顺序）→ 杂盒优先于纯净盒 → 内容物。
- 只移动您原本就拥有的物品。无法安全移动的配对会被跳过，而不是冒险打乱容器。

## 自动补货

补货会把您已有的物品补充到快捷栏和/或副手。

- **唯一触发时机**：手持那一叠数量减少 —— 即使用、放置、进食、投掷或饮用了物品。
  **存入容器不算**：开着界面时无法使用物品，因此这种情况永远不会被当作消耗。
- **阈值**：`restockMinCount`（0–64）。设为 `0` 时规则变为「用光才补」。
- **补充量**：补满一整组 —— 多数物品是 64，鸡蛋、雪球等是 16。
- **来源**：先查您的背包，再查当前打开着的容器。
- **可选的潜影盒来源**：安装 QuickShulker 后，若所需物品只在随身潜影盒里，模组会自动开盒取用、
  之后关闭盒子 —— 期间**隐藏盒子界面并静音**，不会打断您手上的操作。

## 投影联动

安装 Litematica 并开启联动后，SortNStock 会挂在 Litematica `schematicWorldPickBlock` 的头部，
也就是切换快捷栏之前的那个时机，因此**同一次右键就能用上补好的物品**。

- 只在这一个点介入，不做定时轮询。
- **如果所需方块已经存在于背包某处，则不做任何事** —— Litematica 的选取方块能选中持有该物品的
  任意快捷栏格子，也能把它从主背包取出。只有当选取方块确实没有可选项时才会补货，而这正是潜影盒
  能帮上忙的唯一情形。
- 允许填充的快捷栏格子来自 Litematica 自己的 `pickBlockableSlots` 配置。

## 配置

全部配置都在 MaLiLib 生成的配置界面里：快捷键、Mod Menu 按钮，或 MaLiLib 自己的模组列表。
共 15 项，分六个标签页 —— **全部 / 整理 / 自动补货 / 潜影盒联动 / 投影联动 / 调试 / 快捷键**。
每一项的详细说明见 [`docs/CONFIG-REFERENCE.md`](docs/CONFIG-REFERENCE.md)。

## 已知限制

- 整理与补货都是普通容器点击；服务端若拒绝或限流这些点击，可能与本客户端不一致。
- Litematica 的 mixin 针对 0.27.14 的一个精确方法签名；未来版本可能移动它。该 mixin 配置按
  「Litematica 是否存在」做了门控，因此未安装时不会导致模组崩溃。
- 从潜影盒补货需要**服务端也安装 QuickShulker**，因为开盒是自定义数据包。没有时不会发送无效包，
  该功能只是保持不生效。
- 从潜影盒取物需要若干 tick（开盒 → 同步 → 搬运 → 关闭），因此触发投影补货的那一次右键，
  可能在补货完成前就已落地。
